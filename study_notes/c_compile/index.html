使用说明

1. 先在网页中学习和修改

示例文件位于当前目录的 examples 子目录。选择示例会从本地仓库重新读取文件，因此你直接修改示例文件后，刷新或点击“重新加载”即可看到最新内容。

2. 再启动本地编译服务

Windows 用户双击 start_c_compile.bat。服务只监听本机回环地址，并临时创建编译目录；编译结束后临时文件会自动清理。

3. 认识一次编译过程

  • 编译：检查语法、类型和链接错误，同时生成可查看的汇编信息。
  • 运行：先编译，再启动生成的程序；输出显示在右侧黑色面板。
  • 调试构建：保留调试信息，并尝试调用 CDB 或 GDB 输出断点附近的栈和局部变量。

如果电脑没有安装 MSVC、Clang 或 GCC，页面仍可作为纯静态 C 学习编辑器使用；状态栏会明确显示缺少的本地工具。

本页面不依赖外部 CDN，适合在 GitHub Pages 上静态发布。
