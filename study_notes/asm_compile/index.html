汇编学习路线

先区分语法方言

ml64 使用 MASM 风格，nasm 使用 NASM 风格，as 示例使用 GNU 汇编风格。选择示例后，请将编译器切换到匹配的方言。

再观察三个核心问题

  • 数据在哪里：寄存器、栈、静态区和堆分别承担什么作用？
  • 地址如何计算：立即数、寄存器间接、基址加变址和相对寻址有什么区别？
  • 控制流如何变化：比较、条件跳转、循环、调用和返回怎样组合成算法？

示例代码按架构和语法分类存放在 asm_example_code。其中 Windows x64 的 MASM/NASM 示例可以在本机链接运行；ARM64、RISC-V、MIPS 和 68000 示例用于跨架构语法与算法阅读。
