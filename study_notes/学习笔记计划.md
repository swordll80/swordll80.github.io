# c\_compile 目录

c语言在线编辑、编译、运行、调试工具，务必完整支持c语言。
提供了一个方便的在线环境，让用户可以快速编写和测试代码，无需安装任何软件。
可以复用网上的成熟实现方案，但最好都拷贝到本地实现。

# asm\_compile  目录

与c\_compile类似，但专注于汇编语言的在线编辑、编译、运行和调试工具。

# asm\_example\_code

存储asm示例代码，务必覆盖所有asm语法，也覆盖所有技术方向，最简化代码就可以
各种算法思想也都分别举例实现。
asm\_compile  目录下的html文件可以直接调用这些示例代码，方便用户学习和测试。
