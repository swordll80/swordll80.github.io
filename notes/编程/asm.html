汇编语言手册 (x86-64)

19 条
汇编语言速查：寄存器、寻址方式、常用指令、栈与调用约定、系统调用与示例，以 x86-64 为主，附 ARM 简介。
1 汇编是什么
汇编语言：与 CPU 指令一一对应的低级语言，用助记符(mnemonic)表示机器指令。 汇编器(assembler)把 .asm 汇编成机器码：NASM/MASM(Intel 语法)、GAS/as(AT&T 语法)。 用途：理解底层、性能热点、逆向、内核/引导/嵌入式。
2 两种语法
Intel 语法： mov dst, src (目的在前) AT&T 语法： mov %src, %dst (源在前，寄存器带 %, 立即数带 $) 本手册用 Intel 语法(NASM)。
3 程序结构
section .data ; 已初始化数据 section .bss ; 未初始化数据 section .text ; 代码 global _start ; 入口符号 标号: 指令 ; 注释用 ;
4 通用寄存器 (64位)
rax rbx rcx rdx rsi rdi rbp rsp r8–r15 32位: eax… 16位: ax… 8位: al/ah… 惯用：rax 返回值/累加，rcx 计数，rsp 栈指针，rbp 栈帧基址，rsi/rdi 源/目的。
5 指令指针与段
rip：指令指针(下一条指令地址)。 段寄存器：cs ds ss es fs gs(现代多用 fs/gs 做 TLS)。
6 标志寄存器 EFLAGS/RFLAGS
ZF 零标志、SF 符号、CF 进位、OF 溢出、PF 奇偶、AF 辅助进位、DF 方向。 由算术/比较指令设置，条件跳转据此判断。
7 操作数类型
立即数：mov rax, 10 寄存器：mov rax, rbx 内存： mov rax, [rbx] 有效地址：lea rax, [rbx+rcx*4+8] ; 只算地址不取值
8 内存寻址
[base + index*scale + disp] scale ∈ {1,2,4,8} 例：mov eax, [rbx + rsi*4 + 12] ; 访问数组元素
9 数据传送
mov 传送 lea 取有效地址 push/pop 入栈/出栈 xchg 交换 movzx 零扩展 movsx 符号扩展
10 算术与逻辑
add sub 加减 inc dec 自增减 mul/imul 乘 div/idiv 除(结果在 rax, 余数 rdx) and or xor not 逻辑 neg 取负 shl/shr 逻辑移位 sal/sar 算术移位 rol/ror 循环移位
11 比较与跳转
cmp a,b ; 做 a-b 只设标志 test a,b ; 做 a&b 只设标志 jmp 无条件跳；条件跳(据标志)： je/jz 相等/零, jne/jnz 不等, jg/jl 有符号>/<, ja/jb 无符号>/<。
12 函数与栈
call func ; 压返回地址并跳转 ret ; 弹返回地址返回 push/pop 维护栈；栈向低地址增长。
13 典型栈帧
push rbp mov rbp, rsp ; 建立栈帧 sub rsp, N ; 分配局部变量 ... leave ; = mov rsp,rbp / pop rbp ret
函数调用栈帧
14 调用约定
System V AMD64(Linux)：整型参数依次 rdi rsi rdx rcx r8 r9，返回 rax；被调用者保存 rbx rbp r12–r15。 Windows x64：参数 rcx rdx r8 r9，调用者留 32 字节 shadow space。 cdecl(32位)：参数从右到左压栈，调用者清栈。
15 Linux 系统调用
x86-64：调用号放 rax，参数 rdi rsi rdx…，执行 syscall。 write=1, exit=60, read=0, open=2。
16 Hello World (NASM/Linux)
section .data msg db "Hello",10 section .text global _start _start: mov rax,1 ; write mov rdi,1 ; stdout mov rsi,msg mov rdx,6 syscall mov rax,60 ; exit xor rdi,rdi syscall ; 编译: nasm -f elf64 a.asm && ld a.o -o a
17 加法函数
add2: ; int add2(int a,int b) mov eax, edi ; a add eax, esi ; +b ret ; 返回值在 eax
18 ARM 特点
精简指令集(RISC)，定长指令，寄存器 r0–r15(r13=SP,r14=LR,r15=PC)，AArch64 用 x0–x30。 加载/存储架构：运算只对寄存器，访存用 LDR/STR。 参数 x0–x7，返回 x0，返回地址在 LR。
19 常用指令
MOV 传送 ADD/SUB 加减 MUL 乘 LDR/STR 加载/存储 CMP 比较 B/BL 跳转/带链接跳转 BX LR 返回 条件执行与后缀(EQ/NE/GT…)。
