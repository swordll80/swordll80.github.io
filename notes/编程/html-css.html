HTML / CSS 手册

16 条
网页结构与样式速查：常用标签、盒模型、Flex/Grid 布局、选择器与响应式。
1 文档骨架
<!doctype html> <html lang="zh-CN"> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>标题</title> </head> <body>...</body> </html>
2 常用标签
<h1>~<h6> 标题 <p> 段落 <a href> 链接 <img src alt> 图片 <ul><li> 无序列表 <ol><li> 有序列表 <div> 块容器 <span> 行内容器 <table><tr><td> 表格
3 语义化标签
<header> 页眉 <nav> 导航 <main> 主体 <section> 区块 <article> 文章 <aside> 侧栏 <footer> 页脚 -- 利于 SEO 与无障碍，优于全用 div
4 表单
<form action="/x" method="post"> <input type="text" name="user" placeholder="用户名"> <input type="password" name="pwd"> <input type="email"> <input type="number"> <textarea></textarea> <select><option>A</option></select> <button type="submit">提交</button> </form>
5 引入方式
/* 外部（推荐） */ <link rel="stylesheet" href="a.css"> /* 内部 */ <style> p{color:red} </style> /* 行内 */ <p style="color:red">
6 选择器
* 所有元素 .class 类 #id id div p 后代 div > p 直接子元素 a:hover 悬停 input:focus 聚焦 li:nth-child(2n) 偶数项 [type=text] 属性
7 优先级
!important > 行内(1000) > id(100) > class/属性/伪类(10) > 标签(1) -- 尽量避免 !important；用更具体的选择器
8 颜色与单位
color: #356ae6; rgb(53,106,230); rgba(0,0,0,.5); 长度: px 绝对 / em 相对父字号 / rem 相对根字号 % 百分比 / vw vh 视口宽高 / vmin
9 盒模型组成
content → padding → border → margin box-sizing: border-box; /* 宽高含 padding+border，推荐 */ margin: 0 auto; /* 水平居中块 */
CSS 盒模型
10 显示与定位
display: block / inline / inline-block / none; position: static(默认) / relative / absolute / fixed / sticky; z-index: 10; /* 层叠顺序 */ overflow: hidden / auto / scroll;
11 Flex 弹性布局
/* 容器 */ display: flex; flex-direction: row | column; justify-content: center | space-between | flex-start; /* 主轴 */ align-items: center | stretch; /* 交叉轴 */ flex-wrap: wrap; gap: 12px; /* 子项 */ flex: 1; /* 占据剩余空间 */
12 Grid 网格布局
display: grid; grid-template-columns: repeat(3, 1fr); /* 三等分 */ grid-template-columns: 200px 1fr; /* 定宽+自适应 */ gap: 16px; grid-column: span 2; /* 子项跨两列 */
13 常见居中
/* Flex 居中 */ display:flex; justify-content:center; align-items:center; /* 绝对定位居中 */ position:absolute; top:50%; left:50%; transform:translate(-50%,-50%);
14 媒体查询
@media (max-width: 768px) { .sidebar { display: none; } .container { padding: 8px; } } @media (prefers-color-scheme: dark) { ... }
15 过渡与动画
transition: all .2s ease; transform: scale(1.1) rotate(5deg) translateY(-4px); @keyframes spin { to { transform: rotate(360deg); } } animation: spin 1s linear infinite;
16 CSS 变量
:root { --accent:#356ae6; --gap:12px; } .btn { color: var(--accent); padding: var(--gap); } /* 便于统一维护主题色与间距 */
