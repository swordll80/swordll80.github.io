HTTP / 网络手册

15 条
Web 开发必备网络知识：HTTP 方法与状态码、请求头、REST、跨域、缓存与安全。
1 常用方法
GET 获取资源（幂等、可缓存） POST 提交/创建（非幂等） PUT 整体更新/替换（幂等） PATCH 局部更新 DELETE 删除（幂等） HEAD 只取响应头 OPTIONS 预检、查询能力
2 幂等与安全
安全：不改变服务器状态 → GET/HEAD/OPTIONS 幂等：多次调用结果一致 → GET/PUT/DELETE POST 既不安全也不幂等
3 2xx 成功
200 OK 请求成功 201 Created 已创建（POST） 204 No Content 成功但无返回体
4 3xx 重定向
301 永久重定向 302 临时重定向 304 Not Modified 命中缓存
5 4xx 客户端错误
400 请求语法错误 401 未认证（需登录） 403 已认证但无权限 404 资源不存在 405 方法不允许 429 请求过多（限流）
6 5xx 服务端错误
500 服务器内部错误 502 网关错误 503 服务不可用 504 网关超时
7 请求结构
GET /api/users?id=1 HTTP/1.1 Host: example.com Authorization: Bearer <token> Content-Type: application/json Accept: application/json {"body": "..."}
8 常用请求头
Content-Type 请求体类型（application/json、form-data） Authorization 认证凭证 Accept 期望的响应类型 User-Agent 客户端标识 Cookie 携带的 Cookie Referer 来源页面
9 常用响应头
Content-Type 响应体类型 Set-Cookie 设置 Cookie Cache-Control 缓存策略 Location 重定向地址 Access-Control-Allow-Origin 跨域许可
10 RESTful 设计
GET /users 列表 GET /users/1 详情 POST /users 新建 PUT /users/1 更新 DELETE /users/1 删除 -- 用名词复数、用状态码表达结果
11 鉴权方式
Cookie-Session：服务端存会话，浏览器带 Cookie Token (JWT)：无状态，Header 带 Bearer OAuth2：第三方授权（微信/GitHub 登录） API Key：简单的密钥标识
12 JWT 结构
header.payload.signature（Base64 三段，用 . 连接） header 算法类型 payload 载荷（用户id、过期时间，勿放敏感信息） signature 签名，防篡改
13 CORS 跨域
同源 = 协议+域名+端口 都相同 跨域时浏览器拦截，需服务端响应： Access-Control-Allow-Origin: * Access-Control-Allow-Methods: GET,POST 复杂请求先发 OPTIONS 预检
14 缓存
Cache-Control: max-age=3600 强缓存 ETag / If-None-Match 协商缓存→304 Last-Modified / If-Modified-Since no-cache 每次校验；no-store 不缓存
15 HTTPS 与常见攻击
HTTPS = HTTP + TLS 加密，防窃听篡改 XSS：注入脚本 → 转义输出、CSP CSRF：伪造请求 → Token 校验、SameSite Cookie SQL 注入：参数化查询、勿拼接 SQL
