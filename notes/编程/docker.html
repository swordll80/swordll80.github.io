Docker 容器手册

9 条
容器化常用命令与概念：镜像、容器、Dockerfile、数据卷、网络与 Compose。
1 镜像与容器
镜像 Image：只读模板（应用+依赖+环境） 容器 Container：镜像运行的实例（可读写层） 仓库 Registry：存放镜像（Docker Hub、私有仓库） 类比：镜像=类，容器=对象
Docker 镜像分层与容器可写层
2 常用命令
docker pull nginx:1.25 # 拉取镜像 docker images # 列出镜像 docker rmi <image> # 删除镜像 docker tag src:tag new:tag # 打标签 docker build -t app:1.0 . # 构建镜像 docker save/load # 导出/导入 tar
3 run 与生命周期
docker run -d --name web -p 8080:80 nginx -d 后台 -p 主机:容器 端口映射 --name 命名 -e KEY=VAL 环境变量 --rm 退出即删 docker ps -a # 所有容器 docker stop/start/restart web docker rm web # 删除容器
4 进入与调试
docker logs -f web # 查看日志 docker exec -it web bash # 进入容器 docker inspect web # 详细信息 docker stats # 资源占用
5 常用指令
FROM node:20-alpine # 基础镜像 WORKDIR /app # 工作目录 COPY package.json . # 复制文件 RUN npm install # 构建时执行 EXPOSE 3000 # 声明端口 ENV NODE_ENV=production # 环境变量 CMD ["node", "server.js"] # 启动命令
6 构建优化
-- 分层缓存：先 COPY 依赖清单再 install，最后 COPY 源码 -- 用 .dockerignore 排除 node_modules 等 -- 多阶段构建：build 阶段编译，最终镜像只留产物 FROM x AS build ... FROM nginx COPY --from=build /app/dist /usr/share/nginx/html
7 数据卷
docker volume create data docker run -v data:/var/lib/mysql mysql # 命名卷 docker run -v $(pwd):/app app # 绑定挂载 -- 卷用于持久化，容器删了数据仍在
8 网络
docker network create mynet docker run --network mynet --name db ... # 同网络容器可用容器名互相访问 docker network ls / inspect
9 docker-compose
# docker-compose.yml services: web: build: . ports: ["8080:80"] depends_on: [db] db: image: mysql:8 environment: MYSQL_ROOT_PASSWORD: secret volumes: ["dbdata:/var/lib/mysql"] volumes: { dbdata: {} } # docker compose up -d / down / logs -f
