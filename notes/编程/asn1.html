ASN.1 抽象语法标记手册

15 条
ASN.1 (Abstract Syntax Notation One, ITU-T X.680) 用于描述数据结构；编码规则(X.690 BER/DER 等)决定字节表示。广泛用于 X.509 证书、LDAP、SNMP、Kerberos、3GPP。
1 是什么
ASN.1 是一套描述数据结构的“抽象语法”标准，与具体编码分离。 定义(.asn 模块) 说明有哪些字段和类型；编码规则说明如何变成字节。 标准：结构 X.680，编码 X.690(BER/DER/CER)、X.691(PER)、X.693(XER)。
2 编码规则
BER 基本编码规则：灵活，同一值可有多种编码。 DER 唯一化编码：BER 的确定子集，X.509 证书/PKI 必用(可重现、可签名)。 CER：长数据流式。PER：紧凑(电信/3GPP)。XER：XML 形式。
3 典型应用
X.509 数字证书、PKCS 系列、CMS/S-MIME； LDAP、SNMP(MIB)、Kerberos、H.323/SIP、3GPP LTE/5G 信令。
4 常用简单类型
BOOLEAN 布尔 INTEGER 任意大整数 ENUMERATED 枚举 REAL 实数 NULL 空 BIT STRING 位串 OCTET STRING 字节串 OBJECT IDENTIFIER 对象标识符(OID, 如 1.2.840.113549)
5 字符串类型
UTF8String Unicode(推荐) PrintableString A-Z a-z 0-9 及少量符号 IA5String ASCII NumericString 数字与空格 其它：BMPString、TeletexString(历史)
6 时间类型
UTCTime YYMMDDHHMMSSZ (两位年, 证书旧式) GeneralizedTime YYYYMMDDHHMMSSZ (四位年) DER 要求时间用 Z(UTC) 且规范化。
7 SEQUENCE / SET
SEQUENCE：有序字段集合(类似 struct)。 SEQUENCE OF T：同类型 T 的有序列表(数组)。 SET：无序集合；SET OF T：无序列表。 DER 中 SET OF 元素需按编码排序。
8 CHOICE / 可选
CHOICE：多选一(联合类型)。 OPTIONAL：字段可缺省；DEFAULT v：默认值(DER 中等于默认值时不编码)。
9 模块与定义示例
Person DEFINITIONS ::= BEGIN Person ::= SEQUENCE { name UTF8String, age INTEGER OPTIONAL, email IA5String, roles SEQUENCE OF UTF8String } END
10 标签类别
Universal：内建类型(INTEGER=2, OCTET STRING=4, SEQUENCE=16…)。 Application：应用范围。 Context-specific [n]：上下文相关(结构内区分字段)，最常见。 Private：私有。
11 IMPLICIT / EXPLICIT
EXPLICIT：在原类型外再套一层标签(保留原 tag)。 IMPLICIT：直接替换原类型 tag(更省字节)。 模块可声明 DEFINITIONS IMPLICIT TAGS 设默认。 例：age [0] IMPLICIT INTEGER OPTIONAL。
12 TLV 结构
每个值编码为 Tag–Length–Value： Tag(标识类型) + Length(长度) + Value(内容)。 嵌套结构的 Value 内又是若干 TLV(构造类型 constructed)。
BER/DER 的 TLV 编码
13 Tag 字节
第1字节：bit7-6 类别(00普通/01应用/10上下文/11私有)， bit5 = 0 基本 / 1 构造，bit4-0 = 标签号(≥31 用多字节)。 如 0x30 = 构造+Universal 16 = SEQUENCE；0x02 = INTEGER；0x04 = OCTET STRING。
14 Length 字节
短式：0x00–0x7F 直接表示长度(<128)。 长式：首字节 0x80|n，随后 n 个字节为长度(大端)。 0x80 单独 = 不定长(仅 BER，DER 禁用)。
15 解码示例
30 06 02 01 05 01 01 FF 30=SEQUENCE,len=6 02 01 05 INTEGER 5 01 01 FF BOOLEAN TRUE 可用 openssl asn1parse -in cert.der -inform DER 查看。
